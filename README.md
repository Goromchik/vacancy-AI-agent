# Vacancy-AI-agent
Агент помогает разобрать список вакансий и на основе критериев выбрать подходящие для отклика.

Pipeline устроен так: агент читает критерии из criteria.md (направления, навыки, зарплата, опыт, город), загружает вакансии из vacancies.csv, фильтрует нерелевантные, ранжирует оставшиеся по скорингу и отдаёт топ-5 на объяснение LLM.

Обычная логика отвечает за фильтрацию и скоринг: это формализуемые правила, которые быстро и предсказуемо работают без API.

LLM (Groq) используется только для объяснения топ-5 вакансий: она получает готовые факты и формулирует плюсы, минусы и вердикт по каждой вакансии.

Если LLM недоступна, агент не падает: в отчёт записывается явная пометка, что LLM-объяснение не сгенерировано, а сам отчёт всё равно создаётся.

Основное ограничение: используются искусственно созданные данные, а не реально спарсенные вакансии.

Основная сложность: добиться от маленькой модели стабильного формата ответа без галлюцинации (помогла настройка параметров few-shot и temperature)

## Как запустить
1. Установить зависимости
2. Получить API ключ любого доступного LLM
3. Вставить полученный ключ в блок подключения LLM
4. Открыть 'vacancies_agent.ipynb' в Jupyter и выполнить все блоки по порядку
5. Результат смотреть в 'report.md', лог работы — в 'agent.log'
